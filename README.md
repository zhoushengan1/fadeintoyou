# Fade Into You

A mobile-first personal website project inspired by the quiet, nostalgic atmosphere of Mazzy Star's “Fade Into You”.

## Project direction
- Dreamlike teal-green hills, grass and wildflowers at dusk
- A local music player for audio files selected by the site owner
- Searchable resource sections for tools, networking, books and useful content
- Responsive layout designed for phone-first editing and use

## Status
The project is in the planning and prototype stage. The production homepage and deployment configuration are still to be added.
